# gbFeatExtractor: A tool for extracting sequence features from a GenBank annotation file


```
gbFeatExtractor: A tool for extracting sequence features from a GenBank annotation file

options:
  -h, --help            show this help message and exit
  --in inputfile, -i inputfile
                        Input sequence annotation file in GenBank format
  --out outputfile, -o outputfile
                        Output file containing extracted sequence features
  --seqfmt seqformat, -s seqformat
                        Input sequence annotation format
  --outfmt outputformat, -m outputformat
                        Output file containing extracted sequence features
  --feat feattype, -f feattype
                        Sequence feature type to extract
  --translate, -t       Translate coding sequences
  --version, -v         Show version
  --quiet, -q           Show progress

Written by Chrispin Chaguza, St Jude Children's Research Hospital, 2026
```
